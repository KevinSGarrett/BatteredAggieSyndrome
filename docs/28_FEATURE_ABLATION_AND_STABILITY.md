# Feature Family Ablation and Temporal Stability — Wave 10

## Family ablation
Compare the same chronological evaluation plan with and without an entire declared feature family. The comparison must hold all unrelated modeling/evaluation choices fixed as far as practical.

W10 defines the evidence contract and reference summarizers. W17 owns protected empirical model comparison.

## Temporal stability
Evidence must be inspected across chronological folds/seasons/eras rather than a pooled random split. Record direction, magnitude and missing/coverage changes. A feature that works only in one known regime can be CONDITIONAL rather than automatically rejected, provided the condition is knowable at prediction time and independently justified.

## Target-specific evidence
Win probability, margin, team score, opponent score and BAS thresholds can reach different conclusions. Do not force one universal feature set.

## A&M specialization
National value and A&M-specific incremental value are separate questions. A feature must not be called valuable for Texas A&M solely because it is useful nationally, or vice versa.

## No W10 performance claim
No full-vs-ablated real-data metric is present in W10. Synthetic tests validate implementation semantics only.

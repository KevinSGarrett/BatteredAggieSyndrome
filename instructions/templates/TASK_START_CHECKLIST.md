# Task Start Checklist

- [ ] Canonical repo/worktree identity verified.
- [ ] Git staged/unstaged/untracked/branch/worktree/remote state inspected.
- [ ] Existing owned unfinished work and PRs checked.
- [ ] Correct live Jira BAT project/status mapping verified for writes.
- [ ] Jira issue, parent/epic, dependencies/blockers read.
- [ ] Internal EPIC/TASK, REQ, ADR, AC, source documents resolved.
- [ ] Existing code/tests/schemas/consumers inspected.
- [ ] Shared-contract owner and parallel conflicts checked.
- [ ] One-sentence outcome and in/out scope written.
- [ ] Branch/worktree/agent claim recorded.
- [ ] Focused, impacted, PR-ready validation planned.
- [ ] Security/rights/PIT/resource/rollback stop conditions identified.

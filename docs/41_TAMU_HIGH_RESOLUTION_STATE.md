# Texas A&M High-Resolution State

The A&M overlay increases **evidence resolution**, not canonical authority. It can deepen roster/depth/QB/OL/receiver/availability/staff/regime/unit/context evidence while retaining the same source mapping, bitemporal and provenance rules used nationally.

Missing A&M-specific evidence never becomes a fabricated fact. The fallback is the national canonical state, an explicit unknown/degraded state, or wider uncertainty. Official A&M/SEC evidence may outrank weaker secondary evidence when source priority and timestamp semantics justify it.

Unit state remains evidence, not a manual strength bonus. QB and OL receive especially high-resolution treatment because their roles can be high leverage, but W14 freezes no permanent positional point value.

# New Jira Issue Decision

Create a new issue only when every required answer supports independent tracking.

- [ ] Live BAT access, issue types, fields, and workflow are verified.
- [ ] Duplicate/related issue search completed; results recorded.
- [ ] The outcome is independently meaningful and accept/reject/reviewable on its own.
- [ ] It is not a file/function/test/command/retry/micro-refactor or same-PR documentation step.
- [ ] It is not required to make an existing issue Done.
- [ ] Correct parent and hierarchy are known.
- [ ] Dependencies/blockers are known.
- [ ] Internal task/handoff/REQ/ADR/AC/source references are known.
- [ ] Acceptance evidence and maturity boundary are defined.
- [ ] Owner/priority/Ready gate are known.
- [ ] Creating it will not duplicate GitHub Issues or another tracking system.

Decision: `CREATE | USE_EXISTING | ADD_CHECKLIST/SUBTASK | DEFER/REJECT`

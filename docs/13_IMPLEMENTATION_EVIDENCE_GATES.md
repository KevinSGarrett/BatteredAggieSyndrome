# 13 — Implementation Evidence Gates

## Evidence classes
- **STATIC:** registry/schema/ID/manifest/policy validation.
- **UNIT:** local deterministic behavior.
- **INTEGRATION:** boundary behavior between accepted components.
- **CHRONOLOGICAL_REPLAY:** historical as-of behavior with no future leakage.
- **SCIENTIFIC:** proper scoring, calibration, ablation, significance/stability where applicable.
- **BENCHMARK:** measured local hardware/runtime/resource evidence.
- **MANUAL/LEGAL:** licensing, source semantics or evidence that cannot be safely automated.

## Gate rule
Planning says what evidence is required; only the owning wave can claim that evidence exists. W05 therefore maps tasks to controls without marking W07+ scientific/data/product controls passed.

## No invented thresholds
The W04 threshold registry remains authoritative. W05 does not fill model/data/performance numeric thresholds. Those values are populated only by their evidence-owning waves.

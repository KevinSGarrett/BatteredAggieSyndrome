# W15 Experiment Boundaries

W15 defines BAS labels, cross-fit/chronological rules, null hypotheses, candidate components and W17 evaluation plans.

W15 does **not** train the final expectation model, select W16 model families, run protected significance tests, set `THR-006`, claim Aggie Excess, select a BAS component, calibrate BAS probability or create a live Collapse model.

Synthetic tests validate sign/threshold/provenance/anti-circularity behavior only. They do not establish that BAS exists historically.

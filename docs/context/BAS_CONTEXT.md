# BAS Context

Headline BAS is **P(Texas A&M performs at least 7 points worse than a strictly valid pregame expected margin)**, with nested >=3/7/14/21 severity probabilities.

Sign convention: `performance_residual = actual_margin - expected_margin`; negative is worse than expected; positive shortfall is `expected_margin - actual_margin`.

Historical labels require a BAS-independent, strictly pregame OOS expectation with chronological training cutoff and target canonical-game exclusion. Cross-fitting cannot use future games merely because the target row is held out.

General FBS underperformance is the reference; Aggie Excess is a null-first candidate effect evaluated against predeclared peers/regimes. Offensive/Defensive/Special Teams/Coaching/Collapse components remain experimental; Collapse is live-replay research only.

W15 claims no A&M excess effect, component winner, significance/calibration result or `THR-006` value. Null/no-excess is an explicitly valid final scientific outcome.

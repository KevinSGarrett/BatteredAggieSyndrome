# Data, reuse, and artwork

## Sports data

The project investigates national college football and Texas A&M using multiple source types. Public accessibility, an API subscription, and permission to redistribute a dataset are different things.

- Check provider terms before acquiring, publishing, or redistributing data.
- Preserve source identity and timing for research use.
- Use small synthetic fixtures for public reproductions wherever possible.
- Do not commit credentials, bulk licensed datasets, private medical information, or account-specific exports.
- Do not infer that all data mentioned in a design document is available or approved for use.

The quick start does not include a complete historical data lake or live data service. A user-supplied timestamp is not proof of when a third-party record became available.


# W16 Experiment Boundaries and W17 Handoff

## W16 completed
W16 freezes target, joint-distribution, baseline, simulation, uncertainty, OOD/disagreement and market-lane **contracts/reference logic**.

It does not claim:
- trained performance;
- a winning model family;
- a winning joint-score family;
- calibrated uncertainty;
- an OOD threshold;
- a model-disagreement threshold;
- A&M specialization value;
- BAS significance;
- market incremental value.

## Adaptive sequencing repair
The older W05 backlog used language that could be read as requiring real protected benchmark results in W17 before W19/W20 materialized data/model starters existed.

W16 clarifies the numbered-wave intent:
- W17 freezes protected split, scoring, calibration, subgroup and promotion **protocols**;
- implementation/materialized protected results occur when data/model artifacts exist;
- no W17 design artifact may fabricate historical benchmark values.

`TASK-128` is the recommended first W17 task because protected splits must be frozen before protected evidence is inspected.

## W17 handoff
W17 should establish:
- protected chronological split registry;
- Brier/log loss/calibration/score likelihood/error metrics;
- subgroup/A&M/BAS scorecards;
- baseline comparison rule;
- threshold precommitment process;
- uncertainty/OOD/market evaluation protocol;
- promotion/rejection governance.

Actual empirical values remain absent until real data/model artifacts exist.

# Protected Acceptance Rules

These controls cannot be weakened or reinterpreted by an experiment/research agent to make a candidate pass.

1. Exact prior-wave pair binding and cumulative integrity.
2. No secrets/forbidden artifacts in deliverable packs.
3. PIT known-at eligibility fails closed on ambiguity.
4. Future-information leakage battery must pass before affected model promotion.
5. Canonical-game split safety is protected.
6. BAS historical expected margin must be leakage-safe/out-of-sample.
7. Protected test periods and promotion criteria are fixed before protected-result inspection.
8. Research/LLM plane cannot self-promote production changes.
9. License/redistribution uncertainty cannot be auto-waived.
10. Completion/performance status cannot be fabricated.

Changing a protected rule requires user authority where it is a Level-A invariant or an explicitly permitted governance change with ADR/evidence where appropriate. Historical results are never rewritten to make a new candidate pass.

## W08 protected temporal controls
The following W08 temporal controls are protected and release-blocking: AC-067 through AC-076, in addition to existing PIT/leakage controls AC-011 through AC-016.

Research/feature/model code may not weaken these controls to improve apparent model performance. Changes require explicit governance review/ADR and must preserve historical comparability or document a new evaluation regime.

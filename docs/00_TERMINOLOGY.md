# Terminology

- **Prediction timestamp / as-of:** moment defining what information may be known.
- **known_at / prediction_eligible_at:** earliest defensible time an observation may enter a forecast.
- **Canonical entity:** internal stable identity independent of source-specific IDs.
- **Observation:** dated/effective evidence about a canonical entity.
- **PIT:** point-in-time correctness; historical replay uses only historically available information.
- **National Foundation:** broad FBS/FCS learning layer for general football structure.
- **A&M Specialization:** higher-resolution Texas A&M state/residual/calibration/evaluation layer; exact statistical design remains revisable.
- **BAS:** Battered Aggie Syndrome scientific underperformance target, not loss probability. Headline: P(A&M margin is at least 7 points below valid pregame expected margin).
- **Aggie Excess:** candidate excess underperformance risk beyond comparable general-FBS risk.
- **Champion/Challenger:** governed production model and candidates that must earn promotion.
- **Feature lifecycle:** evidence state such as CORE/SUPPORTED/CONDITIONAL/EXPERIMENTAL/REJECTED/BANNED.
- **Epistemic uncertainty:** uncertainty from insufficient/sparse knowledge.
- **Aleatoric uncertainty:** inherent outcome randomness.
- **OOD:** out-of-distribution condition where current state differs materially from training history.
- **Hydration pack:** compact structured state allowing a fresh session to recover current project state without copying the full repo.

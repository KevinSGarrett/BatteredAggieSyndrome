# GitHub Enforcement Activation Checklist

## Repository identity
- [ ] Trusted `main` exists and matches canonical history
- [ ] Visibility/owner/default branch verified
- [ ] No forbidden artifacts or secrets in initial history

## Merge settings
- [ ] Squash merge configured as selected default
- [ ] Unused merge methods disabled if appropriate
- [ ] Auto-delete merged branches enabled

## Main protection/ruleset
- [ ] PR required
- [ ] Force push disabled
- [ ] Deletion disabled
- [ ] Required checks identified from real workflow runs
- [ ] Conversation resolution configured
- [ ] Required review/code owner rules proportionate
- [ ] Branch update policy chosen

## Security
- [ ] Secret scanning/push protection
- [ ] Dependency graph/alerts/review
- [ ] CodeQL/security workflow
- [ ] Actions permissions reviewed

## CODEOWNERS
- [ ] Valid owner handle/team
- [ ] Critical paths only
- [ ] Required-review rule is satisfiable

# Advanced Challenger Admission

## Principle
Complexity must earn its place.

Advanced candidates include small neural tabular models, temporal/sequence networks, Transformers, graph neural networks, learned play embeddings, and other expensive Phase-5 research.

## Prerequisites
An advanced candidate is admitted only when:
1. W17 rule seal verifies;
2. conventional baseline implementation exists;
3. development baseline evidence exists;
4. a falsifiable hypothesis explains expected incremental value;
5. required data representation is materially available;
6. resource budget is declared;
7. maintenance/explainability cost is documented;
8. protected evaluation compatibility exists.

## Admission states
- BLOCKED_PROTOCOL_UNSEALED
- BLOCKED_BASELINE_MISSING
- BLOCKED_DATA_REPRESENTATION_MISSING
- BLOCKED_RESOURCE_BUDGET_MISSING
- BLOCKED_HYPOTHESIS_MISSING
- ADMITTED_RESEARCH_ONLY

Admission never equals production promotion.

Live/in-game challengers additionally require chronological replay and proof of pregame/live isolation.

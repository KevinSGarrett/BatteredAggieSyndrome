# General FBS Underperformance, Aggie Excess and Peers

Ordinary underperformance is first measured across eligible FBS team-game orientations using the same leakage-safe expectation. Canonical game is the inference cluster because opposite team orientations are dependent.

**Aggie Excess** is a candidate incremental difference between Texas A&M underperformance and a general/peer expectation after predeclared controls/matching. It is not assumed to exist.

Candidate estimands include residual-location difference, shortfall>=7 risk difference/ratio, and hierarchical/partial-pooled A&M effects. Peer definitions come from frozen PIT-safe W14 contracts, never from target outcomes.

W17 must report effect size plus uncertainty, season/regime/peer sensitivity and null findings. A small p-value without stability/practical relevance is insufficient.

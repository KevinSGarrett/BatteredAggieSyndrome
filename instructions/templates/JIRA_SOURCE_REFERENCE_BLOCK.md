# Jira Source-Reference Block

Use stable IDs and links. Do not paste whole plans, credentials, restricted data, or huge logs.

```text
Terminal handoff: HANDOFF-### | N/A
Internal epic: EPIC-###
Internal task(s): TASK-###
Requirements: REQ-###, ...
Direct ADRs: ADR-###, ...
Acceptance controls: AC-###, ...
Canonical source documents:
- path/to/source.md
Dependencies/blockers:
- BAT-### / TASK-### — relationship
Shared contracts / protected surfaces:
- resource/path — owner/gate
Branch/worktree: codex/BAT-###-description | <path>
Pull request: <URL or pending>
Evidence location: <path/link>
Maturity/claims boundary: <what this issue will and will not establish>
```

# Original ideas: delivery and decision plan

**State: planning obligations, not implementation acceptance.**

This plan makes each reviewed original idea actionable: deliver a required behavior, investigate a candidate, or retain an explicit conditional, deferred or withdrawn decision. It does not claim those capabilities are already implemented or scientifically accepted.

The authoritative machine-readable child list is [ORIGINAL_IDEA_DECISIONS.json](../governance/ORIGINAL_IDEA_DECISIONS.json): 85 groups and 515 retained child concepts. Child-specific owner overrides take precedence where one group spans several producers. Each child inherits exact source references, requirement IDs, current canonical Jira owner/local ID, an existing output location and a dependency checkpoint from its group. Historical chat bytes stay private; references publish only identifiers, hashes and line locators.

## How work is selected

- A manager preparing an affected work batch resolves these children against current evidence and the actual owner scope. Related children may be completed in one coherent delivery; no issue or cycle per child is required.
- Required data, invariants and product interfaces are implementation obligations. Proposed statistical features, model forms and interactions require a recorded empirical decision; rejected or unsupported hypotheses remain valid outcomes.
- Before calling a family complete, its named children must be delivered within scope or have an explicit evidence-backed conditional/deferred/withdrawn disposition. A generic feature-family label or populated Jira link is insufficient.
- Deferred work has a dependency checkpoint, not an arbitrary date. Inactive assistive routes, unavailable dependencies and optional advanced models are not automatically reactivated.
- This plan does not amend an active sealed assignment, reopen historical Done issues or require all 515 children before another bounded cycle may proceed. Existing Jira outputs carry child decisions; no new per-child packet bureaucracy is added.
- PIT/known-at, protected exposure, immutable sources/forecasts and empirical adoption remain controlling. Host resource observations remain advisory.

## Disposition meanings

- **IMPLEMENTATION_OBLIGATION:** deliver the named supported behavior or invariant; no existing completion is asserted.
- **CANDIDATE_TO_EVALUATE:** make a predeclared, evidence-backed support/reject/conditional/defer decision.
- **CONDITIONAL_INVESTIGATION:** first determine whether source, definition, timing and population support are adequate.
- **DEFERRED:** retain the idea and owner until its explicit prerequisite changes.
- **WITHDRAWN:** preserve the superseding decision without scheduling the withdrawn proposal.

The unavailable pretrained-model suggestion, SIS as a mandatory dependency, large-LLM-from-scratch focus and retired assistive execution remain withdrawn. PFF, advanced neural/graph work, cloud rental and live-collapse remain conditional or deferred on their existing authority. The scientific objective is useful, calibrated football prediction and honest underperformance analysis, not adoption of every brainstormed technique.

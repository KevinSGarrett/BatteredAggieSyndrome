# Advanced Challenger Admission and Phase-5 Research Gate

> **Wave 18 full-rebuild status:** reference implementation + governance contract. No protected model result or production promotion is claimed.

## Purpose

Complexity must earn its place. Neural, Transformer/sequence and graph methods remain research challengers until conventional baselines and data pipelines exist.

## Admission evidence

Admission requires a materialized conventional baseline, a demonstrated unresolved modeling gap or saturation rationale, protected protocol seal, development-only plan, resource budget, required data coverage, rights clearance, maintenance owner, and a falsifiable incremental hypothesis.

## Examples

A Transformer is not admitted merely because sequence modeling is fashionable. A GNN is not admitted merely because coaches/players form a graph. A neural tabular model is not admitted merely because GPU capacity is idle. Each needs a specific reason conventional approaches are insufficient.

## Post-admission

Admission means research-only. The candidate still enters the model tournament, must beat simple baselines, satisfy W16 coherence, replay successfully, and pass external promotion governance before production.

# Wave 06 Data Research Method

Research date: 2026-08-08

Wave 06 used fresh web research in addition to the reconnaissance pack. Search priority was official API/documentation → governing body → official conference/school → original publisher → reputable secondary documentation only when needed. Technical source claims were anchored to primary/provider documentation.

## Passes
A. Domain discovery.
B. Source discovery.
C. Alternative/fallback discovery.
D. Historical-depth review.
E. Point-in-time feasibility review.
F. Access/license/redistribution review.
G. Gap challenge.
H. Duplication/upstream challenge.
I. Architecture challenge.
J. Engineering/value challenge.

The query-level log is `SOURCE_RESEARCH_LOG.csv`.

## Stopping rationale
The final gap searches concentrated on depth charts, officiating assignments, snap/route/coverage data and tracking. They surfaced commercial/restricted solutions and fragmentary official documents but no new scalable open national source class. Additional searches were therefore producing provider variants rather than materially new source classes. W06 stops at comprehensive practical coverage, not a false claim that every dataset on the internet was enumerated.

## Adoption rule
Discovery is not feature promotion. Source → contract → PIT safety → canonicalization → candidate feature → walk-forward experiment → ablation/stability → promote/reject.
